# Excel Assignment 2 – Data Cleaning and Transformation

## 📌 Overview
This project is part of the Data Analytics Excel assignment. It focuses on cleaning, preparing, transforming, and formatting a product dataset using Microsoft Excel.

## 🛠️ Tasks Performed
- Missing value handling
- Data standardization
- Duplicate removal
- Product ID splitting
- Brand and Product Name merging
- Currency formatting
- Date formatting
- Conditional formatting

- `Assignment_2_Data_Cleaning.xlsx` – Cleaned Excel dataset
- `Excel_Assignment_2_Report.pdf` – Assignment report with screenshots and explanations
